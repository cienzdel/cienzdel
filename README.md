# Consejo de Estudiantes de la Facultad de Ciencias

El Consejo de Estudiantes de Ciencias es el órgano de representación del estudiantado de la Facultad de Ciencias de la Universidad de Zaragoza. Reúne a los representantes de todas las titulaciones de la Facultad y coordina su participación en el Consejo de Facultad, sus comisiones y el Consejo de Estudiantes de la Universidad.

Aquí publicamos el código y las herramientas que usamos para trabajar con transparencia.

## Herramientas

| Repositorio | Qué es | Abrir |
|---|---|---|
| [reglamento](https://github.com/cienzdel/reglamento) | Reglamento del Consejo: buscador, comparador entre el texto en vigor y la propuesta nueva. | [web](https://cienzdel.unizar.es/reglamento) |
| [plataforma-votaciones](https://github.com/cienzdel/plataforma-votaciones) | Plataforma de votaciones verificable con firmas ciegas (RFC 9474) para órganos de representación estudiantil. | [web](https://cienzdel.github.io/plataforma-votaciones/) |
| [plataforma-votaciones-datos](https://github.com/cienzdel/plataforma-votaciones-datos) | Archivo público de las votaciones: avisos de apertura, tablones, sorteos y cadena de hashes. | [web](https://cienzdel.github.io/plataforma-votaciones-datos/) |
| [ayudas](https://github.com/cienzdel/ayudas) | Anexos de las ayudas del Vicerrectorado a Consejos de Estudiantes: formulario web que genera el PDF listo para firmar. | [web](https://cienzdel.github.io/ayudas/) |
| [reparto-gastos-ciencias](https://github.com/cienzdel/reparto-gastos-ciencias) | Herramienta para repartir gastos entre pagadores. | [web](https://cienzdel.github.io/reparto-gastos-ciencias/) |
| [plantillas-latex](https://github.com/cienzdel/plantillas-latex) | Plantillas LaTeX del Consejo: actas, convocatorias, resoluciones y certificados. | |
